# Roborta VS Rigoborto example

In this sexample you can find the source files for the Rigoborto vs Roborta example described in the paper:

*Stochastic Polytopal Games, Principles of Formal Quantitative Analysis Essays Dedicated to Christel Baier on the Occasion of Her 60th Birthday*

The file `roborta-plain.prism` contains the specification, a set of equations models the terrain adding uncertainty to the
scenary.

A script is also provided to replicate the results reported in the tool paper.
